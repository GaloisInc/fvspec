Provide it with JSON arguments such as `{"dep_name": "module.helper", "python_source": "<python snippet>"}` (include any optional metadata if helpful). Only proceed to the final theorem statements once the dependency tooling succeeds or reports diagnostics you cannot fix; surface any diagnostics you receive in the reasoning.
